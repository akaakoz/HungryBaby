# HungryBaby

離乳食・幼児食をサポートするiOSアプリです。

## 機能

### 冷蔵庫検索
冷蔵庫にある食材を登録して、レシピを検索できます。

- **食材の手動追加** — テキスト入力で食材を追加
- **レシート撮影** — カメラでレシートを撮影すると、OCRで食材名を自動認識して一括追加
- **こどもレシピで検索** — 登録した食材をもとに [こどもレシピ](https://kids-recipe.com/) でレシピを検索
- 追加した食材は SwiftData に永続保存されます

### 月齢ガイド
赤ちゃんの月齢に応じた食材の安全性を確認できます。

- **7段階のステージ** — ゴックン期（5〜6ヶ月）からパクパク期（12〜18ヶ月）、1歳半、2歳、3歳以上まで対応
- **食材の安全性表示** — 各食材ごとに OK / 注意 / NG を色分け表示
- **アレルゲン表示** — 主要アレルゲン食材にはラベルを表示
- **食材詳細** — 食材をタップするとステージ別の安全性やサイズガイドを確認

### 設定
- 赤ちゃんの生年月日・ニックネームを変更
- 生年月日から現在のステージを自動判定

## セットアップ

### 必要環境
- Xcode 26.5+
- iOS 26.5+

### ビルド手順
1. リポジトリをクローン
2. `HungryBaby.xcodeproj` を Xcode で開く
3. ビルドターゲットを選択して実行

初回起動時にオンボーディング画面が表示されます。赤ちゃんの生年月日を入力すると、月齢に応じたステージが自動設定されます。

## 技術構成
- **SwiftUI** + **MVVM**
- **SwiftData** — データ永続化
- **Vision** — レシートOCR（テキスト認識）
